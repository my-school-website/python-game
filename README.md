# لعبة اختبار قواعد البيانات - الصف التاسع

لعبة تعليمية نصية بلغة Python لمراجعة أساسيات قواعد البيانات.

## المحتوى
- 5 دروس.
- 25 سؤالًا.
- اختبار كامل من 25 سؤالًا.
- اختبار عشوائي من 10 أسئلة.
- خلط الأسئلة والاختيارات.
- تصحيح وحساب النسبة المئوية.

> ملاحظة: الأسئلة صيغت من المعرفة العامة حول موضوع قواعد البيانات وليست منسوخة من الكتاب المدرسي.

## التشغيل محليًا

يتطلب Python 3.10 أو أحدث.

```bash
python database_game.py
```

## GitHub Actions

يحتوي المستودع على Workflow يفحص صحة ملف Python تلقائيًا عند كل Push أو Pull Request إلى فرع `main`.
