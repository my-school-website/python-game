# 🎮 لعبة قواعد البيانات - الصف التاسع

لعبة تعليمية تعمل مباشرة في المتصفح، وتحتوي على 5 دروس و25 سؤالًا في موضوع قواعد البيانات.

## المحتويات

- `index.html` واجهة اللعبة.
- `style.css` التصميم المتجاوب.
- `script.js` الأسئلة ومنطق اللعبة.
- `.github/workflows/deploy.yml` نشر اللعبة تلقائيًا عبر GitHub Pages.

## طريقة الرفع إلى GitHub

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع جميع محتويات هذه الحزمة إلى الفرع `main`.
3. انتظر تشغيل GitHub Actions.
4. من **Settings → Pages** تأكد أن النشر يستخدم **GitHub Actions**.
5. افتح رابط GitHub Pages الذي يظهر في إعدادات المستودع أو في عملية Actions.

اللعبة لا تحتاج Python ولا تحتاج إلى تثبيت أي مكتبات، وتعمل من المتصفح على الكمبيوتر والتاب والجوال.
